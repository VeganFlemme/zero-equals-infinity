# 📚 Site Web Interactif - ∅ = ∞

## 🌟 Description

Site web moderne et interactif présentant le livre "∅ = ∞ - La Théorie Dimensionnelle de la Conscience".

## 🎨 Caractéristiques

### Design Visuel
- **Thème cosmique/quantique** avec palette de couleurs inspirée de l'univers
- **Particules animées** en arrière-plan créant un effet immersif
- **Gradients dynamiques** et effets de lumière
- **Design responsive** adapté à tous les écrans

### Interactivité
- **Navigation fluide** avec smooth scroll
- **Animations au scroll** pour révéler progressivement le contenu
- **Cartes de chapitres interactives** avec effets de survol
- **Modal** pour afficher le contenu complet de chaque section
- **Table des matières cliquable**

### Navigation
- Barre de navigation fixe qui s'adapte au scroll
- Menu burger pour mobile
- Liens vers différentes sections
- Indicateur de scroll sur la page d'accueil

## 📂 Fichiers

- `index.html` - Page web principale (30 Ko)
- `book_data.js` - Données du livre (659 Ko) - 58 sections complètes

## 🚀 Utilisation

### Option 1 : Ouverture directe
1. Téléchargez les deux fichiers (`index.html` et `book_data.js`)
2. Placez-les dans le même dossier
3. Double-cliquez sur `index.html` pour l'ouvrir dans votre navigateur

### Option 2 : Serveur local
Pour une meilleure expérience, utilisez un serveur local :

**Python 3:**
```bash
python -m http.server 8000
```

**Python 2:**
```bash
python -m SimpleHTTPServer 8000
```

**Node.js (avec npx):**
```bash
npx http-server
```

Puis ouvrez `http://localhost:8000` dans votre navigateur.

## 💡 Fonctionnalités Techniques

- **Aucune dépendance externe** - Tout le code est autonome
- **JavaScript vanilla** - Pas de framework requis
- **CSS moderne** avec animations fluides
- **Canvas HTML5** pour les effets de particules
- **IntersectionObserver API** pour les animations au scroll
- **LocalStorage ready** - Prêt pour sauvegarder l'état de lecture

## 🎨 Personnalisation

Vous pouvez facilement personnaliser :
- Les couleurs dans les variables CSS (`:root`)
- Le nombre de particules (variable `particleCount`)
- La vitesse des animations
- Le layout des cartes de chapitres
